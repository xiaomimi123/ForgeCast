# ant-design-pro 商业化分析

## 一句话：这是给谁的什么
给不懂技术的中国中小老板一套二次开发的“经营管理系统”外壳：用微信就能看经营数据、管订单/客户/库存，替换掉他们手里那堆 Excel 和微信群记录。

## 目标买家画像（主攻1个，备选2个）
- 主攻：年营收 300 万~3000 万的贸易/批发/连锁门店老板，没有 IT 团队，现在用 Excel + 微信群管业务，每年花 1~3 万买进销存或收银软件，遇到不匹配还不敢升级。
- 备选1：给中小企业做管理系统的外包开发团队，现在每单手工搭前端耗 2~4 周，买这个换皮模板可缩短到 3~5 天。
- 备选2：行业 SaaS 创业公司，需要一周内做出可给投资人演示/给种子客户试用的 MVP。

## 痛点清单（按付费意愿排序，每条注明"现状成本"）
1. 经营数据散在 Excel、收银机、各家微信群，老板不知道当天到底赚多少（现状成本：每周至少 2 天人工汇总，库存积压/缺货损失每年 5~20 万）。
2. 找有经验的开发公司定制一套管理系统要 10~30 万、等 2~6 个月（现状成本：钱 + 时间，期间业务照旧混乱）。
3. 市面 SaaS 功能固定，开单/提成/欠款等规则改不了，员工用着别扭（现状成本：年费 6000~20000 元 + 落地失败、员工继续用 Excel/纸质单据）。
4. 店内机密（客户资料、进货价）都在员工个人微信/Excel 里，人走数据丢（现状成本：核心员工离职带走客户，重新获客成本翻倍）。

## 换皮方向建议
- 品牌名候选×3：掌柜眼 / 生意罗盘 / 经营一台
- 主打功能砍/留建议：
  - 留：登录与权限（老板/店长/员工分权）、Dashboard 经营看板（今日营收/毛利/欠款）、标准表格列表（客户/订单/库存）、基础表单（录入/编辑）、账户设置。
  - 砍：AI 助手、i18n 多语言、Monitor/Profile/Result/Exception 等纯展示模板、内置 mock（生产环境不用）。
  - 建议先选 1 个细分行业（如商贸批发、汽修、餐饮）做垂直版，再横向复制。
- 需要新增的 1-2 个本土化功能：微信扫码登录 + 公众号“每日经营日报”推送；对接抖音来客/美团商家/旺店通/金蝶等本土平台数据；支持一键导入历史 Excel。

## 定价建议
- 部署价：标准版 ¥9,800 / 套（含部署 + 1 年在线维护），定制起步价 ¥30,000 起。
- 参照物：有赞微商城年费 ¥6,800~¥12,800，微盟类似；企业定制外包起步 5 万。
- 若面向开发者卖源码授权，可定 ¥2,000~¥8,000。

## 钩子匹配（核心输出，直接喂给 M4）
- 副业型：适用度 高 + 一句示例标题：程序员副业：用免费开源后台给本地加油站做会员系统，一单收了 1.8 万
- 信息差型：适用度 高 + 一句示例标题：别再花 10 万定制后台了，阿里开源的这套框架换个皮就能给老板报价
- 接单故事型：适用度 高 + 一句示例标题：接了个"老板数据看板"的单，前端直接用开源模板，3 天交付赚了 3 万
- 行业痛点型：适用度 中 + 一句示例标题：批发店老板还在拿 Excel 算账？这套系统让他手机上盯客户欠款和账期

## 风险
- 协议细节：Ant Design Pro 本身可商用（MIT License）但不能用“Ant Design”商标误导；换皮后需保留依赖项版权声明。
- 竞品是否已在小红书打这个点：已大量存在“后台管理系统源码”、“低代码/无代码搭建”内容，直接说“换皮”会被骂割韭菜，需包装成“给老板做定制系统”而不是“卖模板”。
- 交付难点：这个仓库只有前端和 mock，没有后端、数据库和真实业务逻辑；要补接口开发、服务器部署、数据迁移、人员培训，中小老板又要求“马上能用”，实际交付周期和售后成本容易被低估。
