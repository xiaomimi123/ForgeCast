## §5.4 封面截图注入

**现状**：`buildCoverHtml` 只填 `{{main}}/{{sub}}`；`annotate.html` 截图位是硬编码占位文字；generate 不传 template → 恒用 bigtext（纯文字）。

**目标**：copy 渲封面时自动取产品截图填入"截图+标注型"(annotate)模板。

**截图源优先级（每级 fail-soft，失败降级下一级）**：
1. `workspace/<slug>/raw/` 第一张图片（.png/.jpg/.jpeg/.webp）→ 直接用
2. `workspace/<slug>/raw/` 第一个视频（.mp4/.mov）→ ffmpeg 抽首帧（系统 ffmpeg，本机已确认可用；失败则降级）
3. `project.demo_url` → Playwright 打开截图（联网；仅 demo_url 非空时）
4. 都没有 → 无截图

**填槽**：截图读成 base64 data URI 注入（避免 setContent 的 file:// 跨源问题）。
**模板选择**：有截图 → `annotate`；无 → `bigtext`（现状，不回归）。contrast 保留可显式选，不自动选。

**改动**：
- `cover.ts`：`buildCoverHtml(tpl,{main,sub,shot?})` 加 `{{shot}}` 填充；新增 `pickRawShot(rawDir)`(返回 {kind:'image'|'video',path}|null，图优先)、`imageToDataUri(path)`、`videoFrameDataUri(path)`(ffmpeg，失败 null)、`urlShotDataUri(url)`(playwright，失败 null)、`resolveCoverShot({rawDir,demoUrl})`(按上面 4 级返回 dataUri|null)。`renderCover` 增 `shotDataUri?`/`template?`。
- `annotate.html`：`.shot` 改 `background-image:url('{{shot}}')` + `background-size:cover` 居中，去掉占位文字。
- `generate.ts`：封面块内 `resolveCoverShot` → `template = shot?'annotate':'bigtext'` → `renderCover({...,template,shotDataUri:shot})`。仍全程 try/catch（封面失败不阻断文案）。

**测试**：`pickRawShot`(图>视频>无)、`buildCoverHtml` 填 `{{shot}}`、`imageToDataUri`(mime+base64)。Playwright/ffmpeg 路径 fail-soft、不单测——用**真渲染验证**（造 raw 图 → 渲 annotate → 抽帧确认封面含该图）。

## §5.2 第三内容类别（开发过程碎片）

**现状**：`schedule.ts` 只建模 demo/income 两类；缺"20% 开发过程碎片（Claude Code 录屏、不带货）"。

**目标**：calendar 按 60/20/20 三类检查库存，缺哪类提示补哪类。

**改动**：
- `schedule.ts`：`category(hook)`→`'demo'|'income'|'process'|null`（pain/infogap→demo，story/sideline→income，`'process'`→process）。`CalendarView.mix` 扩为 `{demo,income,process,targetDemo:0.6,targetIncome:0.2,targetProcess:0.2}`。近 7 天三类计数；建议排序改为**按类别缺口(target−share)降序**优先，再最久未发。新增 `gaps: string[]`——列出低于目标且无库存的类别提示（如"开发过程碎片 目标20%、当前0条：去录一条 Claude Code 过程"）。
- 过程碎片资产入库：CLI `forgecast clip add <slug> --file=<workspace相对路径>` → 插 video 资产 `hook='process'` status='draft'（走既有 approve→publish 生命周期）。`hook='process'` 仅存 DB 字符串，不改 TS HookType、不涉及 copy 模板。
- 消费端：`apps/web/src/api.ts` 的 `CalendarView.mix` 加 process/targetProcess + `gaps`；`CalendarPage.tsx` 展示第三类与 gaps；CLI `calendar` 打印三类 + gaps。

**测试**（ops schedule）：`category('process')`；三类 mix 计数与 target；process 无库存时 gaps 含提示；clip add 后（approve）→ inventory/mix 计入 process。
