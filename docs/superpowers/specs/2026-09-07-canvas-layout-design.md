# 画布拖拽排版（子项目⑤第一期）设计

> 日期：2026-09-07　状态：设计已确认，待写实施计划
>
> 用户目标：把剪辑台补齐为**可持续复用的特效与排版工作台**。功能盘点定了四个方向——A 画布拖拽排版、B 特效库升级、C 预设与模板固化、D 素材图层入口。本 spec 只覆盖第一期 A；B/C/D 各自后续独立 spec。

## 0. 决策记录

| 决策点 | 结论 |
|---|---|
| 第一期方向 | A 画布拖拽排版（B/C 建在它之上，预览即所得先做顺） |
| 交互深度 | 拖动 + 缩放 + 对齐线（不做旋转） |
| 可拖图层 | 除视频底片外全部（text/caption/image/shape/卡片）；视频层不可选中 |
| 模板范围 | 全部六模板（talk + flash/story/demo/insight/hybrid） |

## 1. 定位模型：文档流 → 按需固化为绝对定位

现状：图层位置由模板 CSS 文档流决定（卡片贴顶顺排），`style.x/y` 可选、LayerView 只设 `left/top`。拖拽的前提是每层有确定的绝对坐标，因此：

- **测量落地（关键机制）**：预览画布对图层元素做 `getBoundingClientRect`/`offsetLeft` 系测量（换算回 1080×1920 画布坐标；横版 1920×1080）。用户**开始拖某层的那一刻**，把测得 x/y/width 写进该层 `style` 一次性固化；之后该层完全由 style 驱动。
- **没拖过的层保持文档流**——已出厂视频零观感变化（等价门禁思路的延续）。不做「打开即全员固化」，避免旧项目一打开就产生 diff。
- LayerView 补语义：`style.x != null || style.y != null` ⇒ 该层 `position:absolute`（现状只设 left/top 未保证脱离文档流，需补齐并验证六模板不破版）。
- 字幕层 `.cap` 现为 `bottom:150px` 定位；拖过后同样转 top 驱动。
- 坐标单位统一画布 px，Remotion 与预览共用同一坐标系，预览即所得。

## 2. 画布交互

- **选中**：点图层即选中（与 ShotList/时间轴共用同一选中状态）；高亮描边+四角手柄。点空白/点视频底片取消选中。
- **拖动**：改 `x/y`；全程 `applyTransient`（Player 即时跟随），松手 `commit`——一次拖拽=一步 undo（③约定）。
- **缩放**：四角手柄改 `width`；文字/卡片/字幕层按宽度比例**等比联动 `fontSize`**；图片/形状层自由改 width/height，不动字号。不做旋转。
- **对齐吸附**：画布中线（横/竖）、其他图层左/中/右边缘、安全边距线（四边 60px）；吸附阈值 8px（画布坐标）；Alt 按住临时禁用。
- **键盘**：方向键 1px、Shift+方向键 10px；Delete 沿用现有删层规则（仅手动层）。
- **时机门槛**：Player 暂停时才可拖。测量取无动效变换的布局位置（`offsetLeft/offsetTop`，不受 GSAP transform 影响）。
- **Inspector 联动**：X/Y/宽/字号数字框与画布双向同步（同一 op `setLayerStyle` 的两只手）。

## 3. 边界与取舍

- 缩放不动文字/卡片层 `height`（内容撑开，强设会截字）。
- 允许部分拖出画布（压出画面构图是合理需求），但至少 40px 留在画布内。
- `lower()` 单向铁律不变：拖拽只写 `style`，语义层不动；`overridden` 照常置位并提示。
- 重置两级：③既有的一键回生成态=全局重置；新增 Inspector「清除位置覆盖」=单层重置（删 x/y/width/fontSize，回文档流）。
- 测量失败（未渲染/display:none）：该层不可拖，静默。
- 固化后 spec 照常过 `validateSpecPut`（x/y/width 为既有字段，server 零改动）。

## 4. 测试与验收

- **editing**：新增纯函数 `snapPosition`（输入拖动坐标+其他层框+画布尺寸 → 吸附后坐标+命中参考线），全量单测+阈值边界；零 Node 守护照常。
- **compositions**：`style.x/y` 存在 ⇒ `position:absolute` 断言；六模板 fixture 各挑一层带 x/y 验不破版（内容门禁延伸）。
- **①②门禁红线**：无 x/y 的既有 fixture 渲染结果不得变化。
- **端到端真渲**：拖卡片到画布中央+缩放 → 保存 → 真渲抽帧，成片位置与预览一致（±3px）。
- **浏览器自测**：临时 workspace+独立 db，走查拖/缩/吸附/undo/重置。

## 5. 非目标

旋转；多选/成组；图层 z 序调整 UI（track 已有语义）；B 特效库/C 预设/D 素材入口（各自后续 spec）；视频层拖拽与 object-fit 语义（画中画时再做）。

## 6. 风险与已知取舍

- 文档流固化点的测量依赖预览 DOM 与 Remotion 渲染布局一致——②以来两者同源（同一份模板 CSS），端到端 ±3px 验收兜底。
- 等比字号联动对多行文本可能引起折行变化（宽度变了折行点跟着变）——属所见即所得的自然行为，不做特殊处理。
- 六模板文档流各异，固化启动位置的正确性靠六 fixture 门禁+真机走查双保险。
