# 全站视觉重构「锻造车间」主题设计

日期：2026-08-09　状态：已与用户逐节确认
设计稿：`designs/forgecast-restyle/Style Directions.html`（方向 C 为准，A/B 为落选备档）

## 目标

把用户选定的「C · 锻造车间」风格（暖纸底 + 粗墨描边 + 硬阴影 + 炉火橙，呼应 ForgeCast「锻造」品牌隐喻）落成全站设计体系，`apps/web` 七个页面 + board 组件整体换皮。**页面结构、逻辑、交互零改动，纯视觉替换。**

## 1. 设计体系（tokens）

### 色板（index.css 定义 CSS 变量，Tailwind v4 @theme 注册）
| token | 值 | 用途 |
|---|---|---|
| `--paper` | `#f7f2ea` | 页面背景 |
| `--card` | `#fffdf8` | 卡片/面板底 |
| `--ink` | `#1c1712` | 正文、描边、激活反白底 |
| `--sub` | `#5f574c` | 次级文字 |
| `--faint` | `#989083` | 弱化文字/占位 |
| `--hairline` | `#cfc6b8` | 弱描边（chips、分隔） |
| `--fire` | `#d9481c` | 唯一强调色：主按钮/激活/分数/收藏/NEW |
| `--fire-soft` | `#fbe9e2` | 橙晕底（激活 chip、收藏底） |
| `--danger` | `#b91c1c` | 错误提示（保留必要语义色） |

不引入第二彩色；成功/完成态用墨色实底或描边表达。深色模式不做。

### 形状语言
- 卡片/面板：`2px solid var(--ink)` 描边 + 圆角 8-10px + **硬阴影 `4px 4px 0 rgba(28,23,18,.85)`**（实色偏移非模糊）
- 主按钮：橙底白字 + `2px` 橙描边 + `3px 3px 0` 硬阴影；次按钮：卡片底 + 墨描边 2px；小按钮 1.5px 描边
- tab：墨描边分段器（相邻项 2px 墨分隔线），激活项墨底纸色反白
- chip：`1.5px` hairline 描边圆角胶囊，激活态橙描边 + 橙晕底 + 橙字
- 徽章（NEW/今日入炉）：橙底白字小标签 + 2px 硬阴影，悬出卡片右上角
- 导航壳：纸底 + 底部 2px 墨线；logo「Forge」墨色 +「Cast」橙色；激活导航项 3px 橙色底边

### 字体与层次
- 字体栈不换（系统 PingFang）；层次靠字重：页面标题/repo 名 800-900 + 负字距，正文 400，标签 700 + 字距 1-2px
- CJK 行高 ≥1.65

### 组件类（index.css 少量自定义类，其余用 Tailwind 工具类 + CSS 变量）
`.card-forge`（描边+硬阴影卡片）/ `.btn-fire`（主按钮）/ `.btn-ink`（次按钮）/ `.seg-tabs`（分段 tab 容器与激活态）——仅这四个，避免平行长出一套类库。

## 2. 落地范围

只动 `apps/web`（`index.css` + 7 页面 + board 组件），后端零改动。

### 找项目页（对齐 C 稿，含小幅布局调整）
- 卡片：owner 小字 + repo 名 900 大字；右上角**分类徽章**（1.5px 描边 stamp 风，字距 2px）；简介两行；`2px 墨线`分隔后「**变现分**大数字（橙，26px 900）+ ⭐stars · license · N天前」一行；「谁掏钱/为何掏」两行（em 标签墨色 800）；底部三按钮：`☆ 收藏`（激活橙）/ `看详情`（墨底反白，flex-1）/ `GitHub ↗`
- NEW 徽章 →「今日入炉」橙标签悬卡片右上
- 顶栏文案：自动抓取状态行 →「每日 HH:mm 进料 · 上次：…」；页标题副文案「从 GitHub 矿脉里挑能换钱的坯料」
- tabs/chips/按钮按体系；每日新增分组标题沿用现逻辑

### 其余页面（套 token，布局不动）
- 导航壳（App.tsx）：按 C 稿导航样式
- 拆解需求（StageLanes）：泳道列纸底浅框，项目卡 `.card-forge` 弱化版（1.5px 描边小阴影）
- 做内容 / 分发营销（含日历、复盘）/ 定制项目（列表+详情+能力卡）/ 设置：白卡→`.card-forge`，蓝主按钮→`.btn-fire`，蓝激活态→橙，tab→`.seg-tabs`，输入框墨描边
- 抽屉（CandidateDrawer）：纸底面板 + 左缘 2px 墨线，内部按体系
- 日志面板（终端黑绿）保持原样——它是功能性输出不是装饰

### 主题文案边界
仅限找项目页上述三处（今日入炉/谁掏钱·为何掏/进料）；其他页面文案一律不动。
