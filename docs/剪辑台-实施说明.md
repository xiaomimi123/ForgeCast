# ForgeCast「做内容」→ 剪辑台 · 实施说明

> 这份文档是给 Claude Code 在 ForgeCast 仓库里直接实施用的。
> 所有色值、字号、控件高度都是从当前运行中的控制台实测出来的，不是新造的一套。
> 目标：**改动尽量小地复用现有视觉语言**，只重组信息架构和布局。

---

## 0. 怎么用这份文档

放到仓库 `docs/剪辑台-实施说明.md`，然后开 Claude Code：

```
读 docs/剪辑台-实施说明.md，先只做第 8 节的 P0，
改完把改动的文件列出来给我，别一次性做完全部。
```

分阶段做，不要让它一口气推平。每个阶段结束跑起来看一眼再往下。

## 1. 范围

**要改的**：`做内容` 工位下的所有页面（文案 / 拍摄脚本 / 成片 / 出视频 / 卡点 / 模板库 / 预览）。

**不要动的**：
- 找项目 / 拆解 / 分发 / 定制 四个工位的内部实现
- 后端接口签名（除非第 6 节明确写了要加字段）
- 现有的色值和字体（第 3 节是把它们抽成变量，不是换掉）

## 2. 信息架构变更

### 现在
```
工位条（5 个大卡片）
└── 二级 tab ×7：文案 | 拍摄脚本 | 成片 | 出视频 | 卡点 | 模板库 | 预览
```

问题：7 个 tab 里有 5 个是**同一条内容的先后阶段**，不是并列选项。做一条片子要来回切 5 次 tab。

### 改后
```
工位条 → 压成一行面包屑（高 52，并入 Header）
└── 二级 tab ×3：剪辑台 | 成片库 | 模板库
```

| 旧 tab | 去处 |
|---|---|
| 文案 | 剪辑台 · 中栏分镜文案列表 |
| 拍摄脚本 | 剪辑台 · 分镜行展开后的内容 |
| 出视频 | 剪辑台 · 右栏渲染参数 |
| 卡点 | 剪辑台 · 底部卡点轨 |
| 预览 | 剪辑台 · 中栏 9:16 播放器 |
| 成片 | 独立 tab「成片库」，承接批量审片 |
| 模板库 | 保留，只读资源页 |

路由建议：
```
/station/content/:projectId/editor          剪辑台（默认）
/station/content/:projectId/editor/:itemId  选中某条内容
/station/content/library                    成片库（跨项目）
/station/content/templates                  模板库
```
项目选择器只作用于 `editor`；成片库是跨项目的。

## 3. Design tokens

从运行中的页面实测。建议抽成 CSS 变量 + Tailwind theme。

```css
:root {
  /* 面 */
  --fc-bg:        #F1F2EE;  /* 页底 */
  --fc-surface:   #FAFAF8;  /* 面板 / 卡片 */
  --fc-surface-2: #FFFFFF;  /* 输入框、当前行 */
  --fc-sunken:    #E7E8E2;  /* 占位、禁用底 */

  /* 墨 */
  --fc-ink:       #181A16;  /* 正文 / 主操作底 */
  --fc-ink-2:     #2A2E24;  /* 主操作 hover */
  --fc-muted:     #6E7368;  /* 次要文字 */
  --fc-faint:     #9AA093;  /* 弱文字 */

  /* 线 */
  --fc-line:      #D9DBD2;  /* 弱描边 / 分隔 */
  --fc-line-2:    #B9BCB0;  /* 强描边 / 控件边框 */
  --fc-line-3:    #EDEEE9;  /* 列表行分隔 */
  --fc-track:     #E3E5DE;  /* 时间轴轨道分隔 */

  /* 强调（锈红） */
  --fc-accent:      #C13A1B;  /* 当前 / 待办 / 播放头 */
  --fc-accent-tint: #F5E4DE;  /* 选中底 */
  --fc-accent-deep: #8F2A13;  /* 链接 hover */

  /* 剪辑台画布（新增，仅此处） */
  --fc-canvas:      #0E100C;
  --fc-canvas-line: #2E322A;
  --fc-mat:         #181A16;  /* 预览区背景，同 ink */

  /* 圆角 */
  --fc-r-xs: 2px;  /* chip / 标签 */
  --fc-r-sm: 3px;  /* 按钮 / 卡片 / 输入 */
  --fc-r-md: 4px;
}
```

字体（三种各司其职，不要混用）：

| 用途 | family | 规格 |
|---|---|---|
| 中文标题、logo、项目名 | `"Noto Serif SC", Georgia, serif` | 21.6/900 · 16.3/700，`letter-spacing:-0.54px` |
| 编号 / 时间码 / 参数值 / 分组标签 | `"JetBrains Mono", ui-monospace, monospace` | 11.5/400，分组标签 9.9 + `letter-spacing:1.2px` |
| 正文 / 分镜文案 / 按钮 | `ui-sans-serif, system-ui, sans-serif` | 正文 14/1.6，副文 12.5，按钮 13 |

**没有 4/8 栅格。** 间距沿用现有实际值：

```
页边 20 · 面板内 14 · 分组内 10 · 图文间 10 · 按钮间 7 · chip 间 5
列表行间 0（用 1px 分隔线）· 卡片行间 8 · 网格 gap 14
```

控件高度：`22`(chip) `24`(筛选/状态) `28`(面包屑/批量条) `30`(主次按钮/输入) `34`(整宽提交) `36`(tab)

## 4. 剪辑台布局骨架

1440 宽下：

```
┌──────────────────────────────────────────────────────┐
│ Header                                     52  固定  │
├──────────────────────────────────────────────────────┤
│ Context（项目选择器 + 3 tab）              44  固定  │
├────────┬──────────────────────────┬──────────────────┤
│ 队列   │ Stage                    │ Inspector        │
│ 300    │ 1fr（最小 620）          │ 320              │  1fr
│ 固定   │  ├ toolbar          46   │                  │
│        │  ├ preview mat  300 固定 │                  │
│        │  └ shot script     1fr   │                  │
├────────┴──────────────────────────┴──────────────────┤
│ Timeline                                  186  固定  │
└──────────────────────────────────────────────────────┘
```

细节：

- **队列列**：工具条 42 / 钩子筛选 40 / 列表 1fr（`overflow-y:auto`）。分组标题 28。
- **Stage toolbar** 46：左=标题 + 状态标签 + 版本；右=`打回重做`(次) + `通过并送分发`(主，唯一实心) + `⋯`
- **Preview mat** 宽 300 固定，背景 `--fc-mat`。画布 9:16，`宽 = 高 × 0.5625`，上下留白 18；播放条 44，与画布同宽。
- **Shot script**：表头 34；行间 `gap:8`；收起行 `padding:9px 11px`，当前行 `padding:11px` + 左边框 3px accent。
- **Inspector**：表头 34（右侧显示「改动 N 项」）；每组 `padding:10px 14px` + 1px 分隔线；底部固定「用新参数重渲」34。
- **Timeline**：头 32；轨道名列 104 固定；轨道 刻度 20 / 分镜 46 / 字幕 30 / BGM 30 / 卡点 26 = 153。

> ⚠️ 轨道名列和轨道行必须都 `box-sizing:border-box`，否则每行会错 1px，累计到底下差 3px。

### 窄屏

| 宽度 | 行为 |
|---|---|
| ≥1440 | 三栏全开 |
| 1240–1440 | 中栏压缩，预览宽跟着降；左右栏不变 |
| <1240 | 右栏收成抽屉，toolbar 出现「参数」按钮 |
| <1040 | 左栏也收成抽屉；时间轴降到 148，只留分镜 + 卡点两轨 |

剪辑台不做移动端。手机上只给成片库的竖列表 + 全屏播放器。

## 5. 组件

### `QueueRow` — 左栏队列行
- 高 **71** = `padding 7×2` + 缩略图 55 + 上下 1px 线
- 缩略图 `31×55`（9:16），图文 `gap:10`
- 内容：编号(Mono 11/700) · 钩子(Mono 10) · 状态点(6×6) / 标题一行 12.5/1.45 截断 / 元信息 Mono 10
- 状态：
  - `default` — 透明底，左条 transparent
  - `hover` — 底 `#F5F6F1`，左条 `--fc-line`
  - `selected` — 底 `--fc-accent-tint`，左条 3px `--fc-accent`，**全列唯一**，与中栏联动
  - `done` — `opacity:.62`，不从列表消失

### `ShotRow` — 中栏分镜行
- `collapsed`：底 `--fc-bg`，1px `--fc-line`，`padding:9px 11px`
- `active`：底白，1px + 左 3px `--fc-accent`，`padding:11px`，展开一行操作条（`只重渲这一镜` 实心 / `换画面素材` / `加卡点`）
- 文案里被模板放大的词用 `--fc-accent-tint` 底 + 1.5px 下划线标出
- **改字即改画面**：失焦或回车触发该镜重渲，不整条重来

### `Clip` — 时间轴分镜片段
- 高 38（轨 46 减上下 padding 4）
- **宽度用 flex 比例，不用百分比**：`flex: <时长×10> 1 0`，这样 gap 和 border 自动被吸收，不会溢出
- `default` / `current`（accent 描边 + tint 底）/ `dragging`（虚线 + 阴影 + 显示时间码，边缘拖拽改时长）

### `BeatMarker` — 卡点标记
- 11×11 菱形，`position:absolute; left:<百分比>`
- 三态：已用（实心 accent）/ 检出未用（实心灰，点一下切分镜）/ 手动加的（描边墨色，重新分析时不覆盖）

### `Button`
| 级别 | default | hover | active | disabled |
|---|---|---|---|---|
| primary | `--fc-ink` 底 | `--fc-ink-2` | `#000` + 字变 `--fc-line-2` | `--fc-line` 底 + `--fc-faint` 字 |
| secondary | 1px `--fc-line-2` | 边框转 `--fc-ink` + 底 `--fc-bg` | 底 `--fc-track` | 边框 `--fc-line` + 字 `--fc-line-2` |
| chip | 1px `--fc-line` | 边框 `--fc-line-2` | accent 选中态 | 淡化 |

**danger 不做独立按钮。** 删除只出现在 `⋯` 菜单里，红字 + 二次确认。失败态里的「重试」用实心红，那是那一处的主操作。

### `StatusTag` — 高 20，Mono 10，**永远不可点**
`待出片`(描边灰) · `渲染中 68%`(accent 描边 + tint 底 + 旋转图标) · `待审`(同上) · `已通过`(ink 实心 + 勾) · `失败`(accent 实心)

### `Field` — 右栏参数行
标签 Mono 12 固定 38 宽，控件高 28。**改动过的值在标签前加 4×4 accent 圆点。**

## 6. 数据模型

现在 UI 上暴露的 `#5 · pain · draft` 是库里的枚举，不该直接给人看。需要一层展示映射。

一条内容是**一个对象**，封面 / 文案 / 视频是它的字段，不是三条记录：

```ts
type ContentItem = {
  id: string
  projectId: string
  seq: number                    // 显示成 #5
  hook: 'pain' | 'side' | 'gap' | 'story'
  status: ContentStatus
  title: string                  // 列表里显示的一句话
  shots: Shot[]                  // 分镜（文案 + 时长 + 素材）
  cover?: { url: string; style: string; status: 'ok' | 'failed'; error?: string }
  render?: {
    url?: string
    durationMs: number
    version: number              // v3
    renderedAt: string
    progress?: number            // 0–100，渲染中
    error?: { code: string; message: string; retries: number; at: string }
  }
  params: RenderParams           // 模板 / 比例 / BGM / 情绪 / 背景 / 烧字幕
  beats?: { atMs: number; source: 'auto' | 'manual'; used: boolean }[]
  bpm?: number
}

type Shot = {
  index: number
  text: string
  startMs: number
  endMs: number
  emphasis?: [number, number][]  // 会被模板放大的字符区间
  assetRef?: string
}

type ContentStatus =
  | 'script_ready'   // 待出片
  | 'rendering'      // 渲染中（配 render.progress）
  | 'review'         // 待审
  | 'approved'       // 已通过 → 进分发队列
  | 'failed'         // 失败（配 render.error）
```

状态流转：
```
script_ready ──出片──> rendering ──成功──> review ──通过──> approved
                          │                   │
                          └──失败──> failed   └──打回──> script_ready
```

展示映射（不要在组件里硬编码中文）：
```ts
const HOOK_LABEL  = { pain:'行业痛点', side:'副业', gap:'信息差', story:'接单故事' }
const STATUS_LABEL = { script_ready:'待出片', rendering:'渲染中', review:'待审', approved:'已通过', failed:'失败' }
```

## 7. 三条硬交互规则

1. **一屏只有一个黑色实心按钮。** 那是推进流水线的下一步。其余全是描边或 chip。
2. **状态标签不可点。** 要动手的动作放在同一行右侧的按钮上。
3. **右栏参数不即时生效。** 累计到底部「用新参数重渲」才提交，表头显示「改动 N 项」。这样才敢让人随便试参数。

批量审片快捷键（成片库）：`J/K` 上下条 · `Space` 播放 · `A` 通过 · `R` 打回 · `E` 进剪辑台。

## 8. 落地顺序

### P0 — 结构性，先做这个
1. 把「封面卡 + 文案卡」合并成一条 `ContentItem`，列表只渲染一张卡。
2. 二级 tab 从 7 个减到 3 个，旧 5 个 tab 的内容按第 2 节表格挪进剪辑台。
3. 工位条压成一行面包屑并入 Header。
4. 删除按钮从卡片角上移进 `⋯` 菜单，加二次确认。
5. 三个态：**骨架屏**（形状占位 + 「正在写第 2/5 句」，逐句流式填入）、**空态**（说明为什么空 + 直接给下一步按钮）、**失败态**（哪一步失败 + 报错原文 + 重试 + 查看日志）。现在的「加载中…」和破图必须全部替换掉。

### P1 — 剪辑台本体
6. 三栏布局骨架（第 4 节尺寸表）。
7. 中栏 9:16 播放器 + 分镜文案列表，改字即改画面、只重渲单镜。
8. 右栏参数检查器 + 暂存提交模型。
9. 底部时间轴：分镜轨 + 字幕轨（先做这两轨）。

### P2 — 效率
10. 成片库批量审片：6 列网格 + 快捷键 + 批量通过 / 批量重渲。
11. 时间轴 BGM 波形轨 + 卡点轨，拖拽改时长、吸附卡点。
12. 窄屏抽屉。
